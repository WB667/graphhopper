 Documentation : Explication du workflow « Mutation Testing »

1. Objectif de la modification
L’objectif de cette modification du workflow GitHub Actions est d’automatiser la vérification du score de mutation du projet (obtenu via PITEST) et de faire échouer le build si le score actuel est inférieur au score précédent.  
Cela permet de garantir que toute modification de code conserve ou améliore la qualité des tests unitaires.

---
2. Choix de conception
a) Exécution de PIT
- PIT est exécuté sur les modules navigation et web-api avec la commande Maven :  
  `mvn -B -pl navigation,web-api -am org.pitest:pitest-maven:1.20.3:mutationCoverage`
- Le choix de ces deux modules vient du fait que ce sont les seuls à devoir être évalués selon les consignes du TP.

 b) Calcul du score
- Le score est calculé en fonction du nombre de mutants tués (Detected) et mutants générés (Generated).  
- Si aucun mutant n’est trouvé (`DET=0` et `GEN=0`), un score nul est enregistré pour éviter une erreur de division.

 c) Sauvegarde et comparaison du score
- Le fichier score.txt contient uniquement la valeur du score final (ex: 32.72).  
- Le workflow télécharge le score précédent via dawidd6/action-download-artifact@v6.  
- Si le nouveau score est plus faible que le précédent, le build échoue automatiquement.

---
 3. Validation de la modification
  Étapes de validation effectuées :
1. Première exécution (baseline) : le score initial est généré et sauvegardé dans l’artifact.  

2. Deuxième exécution (réduction de couverture) : certains tests ont été commentés pour réduire le score de mutation, entraînant un *échec automatique du job avec le message :  
   Score de mutation en baisse.  

3. Résultat attendu confirmé :
   - Le premier run réussit.
   - Le second run échoue, prouvant que le mécanisme de comparaison fonctionne correctement.

---

 4. Résumé des points essentiels
- Workflow déclenché à chaque push.
- Utilise PIT pour générer un rapport de mutation.
- Calcule et stocke le score global dans un artifact GitHub Actions.
- Compare le score actuel au précédent et échoue si celui-ci diminue.
